# Versionsmatrix Redaktions-Agent

Je Version des Hauptworkflows steht hier, was es dazu im Repository gibt: Plan, Testtabelle, Tages-Doku und Workflow-Export. Jede Zelle ist entweder ein Link auf eine Datei im Repository oder ein Satz „gab es nicht: <Grund>“. Die Datei wird bei jeder neuen Version nachgezogen. Stand: Hauptworkflow v23.1 vom 18.11.2026 (v21 bis v23.1 am 19.11.2026 nachgetragen).

Die Versionen der 5 Werkzeuge stehen mit Status, Archivdatei und n8n-Versions-ID in [versionen.md](../versionen.md), die älteren Stände liegen unter [archiv/](../archiv/README.md). Git-Tags gibt es nur für Abgabestände (Tag `v16`, er zeigt auf den Stand v16 der Abgabe), nicht je Workflow-Version.
