# Versionsmatrix Redaktions-Agent

Je Version des Hauptworkflows steht hier, was es dazu im Repository gibt: Plan, Testtabelle, Tages-Doku und Workflow-Export. Jede Zelle ist entweder ein Link auf eine Datei im Repository oder ein Satz „gab es nicht: <Grund>“. Eine Lücke steht also sichtbar da und wird nicht verschwiegen. Die Datei wird bei jeder neuen Version nachgezogen. Stand: Hauptworkflow v16 vom 11.11.2026.

Die Versionen der 5 Werkzeuge stehen mit Status, Archivdatei und n8n-Versions-ID in [versionen.md](../versionen.md), die älteren Stände liegen unter [archiv/](../archiv/README.md). Git-Tags gibt es nur für Abgabestände (Tag `v16`), nicht je Workflow-Version.
